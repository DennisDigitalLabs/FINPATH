# Chapter Six: Conclusion and Recommendations

## 6.1 Conclusion

FINPATH demonstrates how machine learning, explainability, and personalized decision support can be combined to address financial inclusion risk assessment for underserved youth in Kenya.

The system integrates a responsive frontend, FastAPI backend, relational database, machine-learning layer, prediction services, explainability components, and personalized recommendations.

## 6.2 Achievement of Objectives

The project addressed the major objectives by:

- Preparing and analyzing financial inclusion data.
- Developing and evaluating machine-learning models.
- Incorporating model explainability.
- Designing a financial assessment workflow.
- Providing prediction and recommendation functionality.
- Developing a secure web-based system.
- Preparing the application for cloud deployment.

## 6.3 Recommendations

Future development should focus on:

1. Continued validation of model performance using representative and current datasets.
2. Periodic model retraining and monitoring for model drift.
3. Continued improvement of explainability and user-facing explanations.
4. Expansion of personalized financial recommendations.
5. Monitoring system security after deployment.
6. Integration with additional reliable financial data sources where appropriate.
7. Usability testing with representative target users.
8. Continuous monitoring of API performance and database health.

## 6.4 Future Work

Future versions could incorporate additional financial inclusion indicators, improved recommendation personalization, model monitoring, expanded analytics, and additional deployment infrastructure.

## 6.5 Final Remarks

FINPATH provides a foundation for applying responsible and explainable machine learning to financial inclusion decision support. Its architecture also allows future improvements to the machine-learning, recommendation, analytics, and user-experience components without requiring a complete redesign of the system.
