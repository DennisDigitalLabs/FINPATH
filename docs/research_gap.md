# Research Gap

Existing financial assessment and financial inclusion systems provide useful analytical capabilities, but there remains a need for solutions that combine financial inclusion risk assessment, explainable machine learning, and personalized decision support within one platform.

Many machine-learning applications emphasize prediction accuracy without providing sufficient explanations that ordinary users can understand. Similarly, financial guidance systems may provide generic recommendations without connecting them directly to an individual's assessed financial risk.

FINPATH addresses this gap by integrating:

- Financial inclusion assessment
- Machine-learning-based risk prediction
- Explainable AI
- Personalized recommendations
- A secure web-based decision-support interface

The project specifically focuses on underserved youth in Kenya, providing a context-sensitive approach to financial inclusion risk assessment and decision support.

## Identified Gap

The central research gap addressed by FINPATH is the limited integration of **prediction, explainability, and personalized financial decision support** for underserved youth within a single system designed for the Kenyan context.

## FINPATH Contribution

FINPATH contributes an integrated architecture that connects user assessment data to machine-learning predictions, interpretable results, and personalized recommendations.

This approach is intended to make machine-learning-based financial assessment more understandable and actionable for end users.
